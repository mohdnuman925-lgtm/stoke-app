# Stoke App — Complete Workout Exercises Directory

This folder contains the complete list of all workouts, rotating weeks, splits, and exercises configured in the Stoke application.

---

## Folder Contents
- [`all_exercises_list.txt`](./all_exercises_list.txt): Plain-text formatted file containing all exercises organized by program and day, plus an alphabetical master index of all 173 unique movements.
- [`workout_programs.json`](./workout_programs.json): Machine-readable JSON containing all programs, weeks, days, target sets, and target reps.
